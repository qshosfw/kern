# 🧰 KERN Recovery Suite (`/apps/recovery.mod`)

A standalone, borderless **P0 Structured Paged (`FLAG_SYSTEM_ACTION`)** KRX recovery module for Quansheng UV-K1 / UV-K5 v3 (`PY32F071xB` + `PY25Q16` 2 MB SPI Flash).

`/apps/recovery.mod` works both **independently** (launched from Kern OS) and **cooperatively** with:
- `/apps/dfu.mod` — instant zero-flash `EXC_RETURN` jump from DFU `[MENU] Tools`, and `[EXIT] DFU` handoff back to DFU.
- `/apps/multiboot.mod` — shown in the Recovery menu automatically when installed; returns to Recovery on exit.
- `/apps/calib.mod` — shown in the Recovery menu automatically when installed; returns to Recovery on exit.

---

## ✨ Features

- **Borderless Full-Screen UI:** Zero wasted top title bars; Settings-style outline selection at rest and solid inverted fill while holding `MENU`. Scrollable lists right-align values at `x = 121` clear of the `x = 125` scrollbar.
- **On-Device Firmware Flashing (`Flash Image`):** Flat borderless 5-row browser across `/boot`, `/apps`, and `/` supporting:
  - **`.kfw` v1.0** (`\x89KFW\r\n\x1a\n`, both `COMP_NONE` and `COMP_PACKBITS_RLE` `--mcu-ota` generated by `./kern build`)
  - **`.uf2`** (UV-K1 family `0x7D7A66EF`, 256-byte page blocks)
  - **Raw ARM `.bin`** (vector-validated up to `120,832 B`)
- **Complete Anti-Brick SRAM Flasher (`leaf8..leaf10`):**
  1. **Battery Guard:** Refuses flashing below `6.80 V` unless USB-C charging is detected.
  2. **Pre-Flight 4-Point Vector Validation:** Decodes and verifies Page 0 (`MSP`, `Reset`, `NMI`, `HardFault`) in SRAM *before* erasing a single page.
  3. **1.0 s Hold-`MENU` Confirmation:** Prevents accidental flashing.
  4. **100% Bare-Metal SRAM Execution:** Masks IRQs (`cpsid i`), disables SysTick, streams physical `PY25Q16` SPI2 KernFS extents directly from SRAM (`KRX_FS_EXTENTS`), enforces a hard `0x0800_2800..0x0801_FFFF` address fence, skips identical pages, skips erase on blank pages, verifies with 1 retry, feeds `IWDG`, draws a live ST7565 progress bar, programs **Page 0 (`0x0800_2800`) LAST**, and performs a clean `SYSRESETREQ` reboot.
- **Applets & Live Console (`Applets`):** Launches `.krx` / `.ram` / `.mod` utilities from KernFS with an 8-row scrollable live-streaming console.
- **Peer Flash (`Peer Flash`):** DFU-matched `TX ───▶ RX` 2-pin K1 (`38400` baud) radio-to-radio hub with blinking link arrow.
- **Hardware Diagnostics (`Information`):** 12-row scrollable live diagnostics (`Bootloader`, `Firmware`, `App Flash`, `Vectors`, `Battery`, `Calib`, `USB ID`, `MCU`, `Memory`, `QS-1 Tag`, `UID Hi`, `UID Lo`).

## 🏗️ Modular Layout (10 Leaves, `10,344 B`)

```text
packages/recovery/
├── README.md
├── build.sh                     # Cortex-M0+ PIC build, size/reloc/GOT guards & KRX packer
├── krx.ld                       # Shared Thumb-1 PIC linker script (.text.entry at 0x00000000)
├── recovery.mod                 # Verified P0 Structured Paged module (10,344 B -> /apps/recovery.mod)
└── src/
    ├── rec_shared.h             # RecState, RecScratch, RecFlashJob & resident RecUiOps
    ├── recovery.c               # Resident root (1,916 B): UI ops, SRAM SPI2/LCD/BL helpers & dispatcher
    ├── leaf1_menu.c             # Leaf 1  (804 B): Dynamic borderless Recovery menu (detects multiboot/calib/dfu)
    ├── leaf2_info.c             # Leaf 2  (954 B): 12-row live scrollable hardware/firmware diagnostics
    ├── leaf3_peer.c             # Leaf 3  (843 B): Spacious DFU-matched TX -> RX Peer Flash hub
    ├── leaf4_scan.c             # Leaf 4  (491 B): Flat KernFS scanner (/boot, /apps, /)
    ├── leaf5_files.c            # Leaf 5  (894 B): Borderless 5-row Compact 10 px browser
    ├── leaf6_inspect.c          # Leaf 6  (978 B): Pre-flight KFW v1.0 / UF2 / Raw ARM validator
    ├── leaf7_console.c          # Leaf 7  (937 B): Borderless 8-row scrollable live applet console
    ├── leaf8_flash_chk.c        # Leaf 8  (712 B): Battery guard, KernFS extents & 4-point Page-0 vector check
    ├── leaf9_flash_ui.c         # Leaf 9  (634 B): Error notice & 1.0 s Hold-MENU progress confirmation
    └── leaf10_flash_sram.c      # Leaf 10 (876 B): 100% SRAM-resident SPI2 Page-0-Last flasher & reboot
```
