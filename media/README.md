# Project Media

This directory contains visual media, design assets, and screenshots for Kern.

## Contents

- `screenshots/`: Captured ST7565 display frames (512×256 pixels, 4× scaled from native 128×64 LCD).
  - `boot_system_setup.png`: Visual DFU bootloader verification screen.
  - `app_launcher_grid.png`: Application launcher tile grid.
  - `vfo_dual_watch.png`: Dual VFO display interface.
  - `vfo_step_tuning.png`: Frequency step synthesizer tuning.
